🕷️ 采集器使用说明 tools/naiwa_crawler.py

采集器遵循 robots.txt、记录每张图的来源与授权、按 SHA1 去重，并且内置限速。 请只采集你有权使用的内容。
# 1. 看看内置了哪些来源 python tools/naiwa_crawler.py --list-sources # 2. 干跑：只探测候选链接，不下载 python tools/naiwa_crawler.py --dry-run # 3. 正式采集（最多 120 张，只保留自由授权） python tools/naiwa_crawler.py --limit 120 --license-only # 4. 用自己的源文件（每行一个 URL） python tools/naiwa_crawler.py --sources my-sources.txt --limit 60 # 5. 分析采集结果 python tools/naiwa_data.py stats python tools/naiwa_data.py list --limit 30 # 6. 产出会写到： assets/naiwa-images/manifest.json # 完整清单（含来源 URL 与授权） assets/naiwa-images/derived.json # 衍生数据（角色换色映射） assets/naiwa-images/naiwa-data.js # 前端可直接引用的数据模块
